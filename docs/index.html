THE IDEA, BEFORE THE ARITHMETIC

Compute less. Prove the same answer.

01

Define the valid answers

Numbers between the midpoints to the neighboring floats round to this input. Even significands include the midpoint ties; odd significands exclude them. A valid decimal sits inside this interval.

02

Bound the omitted information

Scale the binary significand with integer arithmetic. Place the residual at the center of its possible error range. Bounds on the omitted cache bits describe how far the exact value can lie from that estimate.

03

Certify or finish exactly

The guards check whether the bounded error could change interval membership, the final digit, or a tie. If it cannot, return the result. Otherwise, reconstruct the needed precision and resolve the choice with the complete integer converter.

WHAT BOUNDRAGON CONTRIBUTES

Spend precision where
the decision needs it.

Boundragon combines centered acceptance guards with explicit cache-error contracts. Binary32 spends its available precision in a 64-bit product; binary64 uses high-word products and compressed caches. Executable certificates check the bounds against the maintained C++ tables.

Origins and related work

The coarse/fine candidate geometry comes from existing shortest-decimal methods. Decimal scaling is credited to xjb, and the exact finish adapts zmij. Schubfach and Dragonbox use interval reasoning; Grisu3 established approximation with fallback. The grid overview below the trace explains this shared foundation.
